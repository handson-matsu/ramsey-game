# TRIANGLE — Ramsey Game

赤・青で辺を塗り、同じ色の三角形を避けるブラウザゲーム。K₅をクリアするとK₆へ進みます。解説・答えの表示はありません。

## 起動・公開

`index.html` をブラウザで開くだけで遊べます。ビルドや依存パッケージは不要です。
GitHub Pagesでは、このリポジトリの公開対象ブランチのルートを配信してください。

- `index.html`: 画面
- `style.css`: レスポンシブデザイン、強調アニメーション
- `logic.js`: 頂点数に依存しない辺生成、三角形判定、ゲーム状態更新
- `app.js`: SVG描画、マウス・タッチ・キーボード操作

辺の近くを押すと最も近い辺を選択します。交差点など複数候補が同程度に近い場合は、頂点番号で辺を選択できます。TabとEnter／Spaceでも操作できます。

## 検証

Node.jsがある環境で `node test.cjs` を実行します。
K₅の全1,024配色、K₆の全32,768配色を別実装の判定と照合します。K₅のクリア可能配色、赤・青両方のゲームオーバー、塗り直し、終了後の操作停止を検証します。

数学的にはK₆でも14本まで単色三角形がない配色は存在します。そのため、15本目の着色で初めてゲームオーバーになる場合があります。三角形判定を全辺着色のクリア判定より先に実行し、K₆が誤ってクリアにならないことを検証しています。

実ブラウザでK₅クリア、K₆への遷移、交差点の選択、ゲームオーバー、操作停止、リトライを確認済み。PC、390px幅、768px幅で表示を確認しています。
